                  Connects two devices directly over the local network — no relay server, no STUN/TURN server, nothing external is ever contacted, not even to set up the connection. The trade-off: there's no server to hold a message for an offline device, so both devices need this dialog open at the same time to pair, and a pairing doesn't survive a page reload, so you'll re-pair (copy/paste two short codes) each time you want to sync this way.
