                              Auto-sync with Google Drive
                              Merges this notebook with a small file in your Google Drive about once a minute while this tab is open, so any other device signed into the same Google account picks up changes automatically — no need for both devices to be open at once. Use "Sync now" for an instant sync. Uses the same credentials as Export/Import to Google Drive.
                              Google Drive connection
                              The API key is not a password. Restrict it in Google Cloud Console by HTTP referrer/origin and limit it to the APIs Nexus uses. The key is stored only on this device in browser storage.
                              Reconnect to Google Drive every
                              How long Nexus may keep your Google Drive connection alive in the background before asking you to sign in again by hand. Google's own tokens expire about hourly whatever you pick here — a shorter setting means Nexus stops quietly renewing them sooner, which is the safer choice on a shared or borrowed computer.

                              Privacy
                              Passcode lock
                              Off — your notes are stored on this device without encryption.
                              Backups you export aren't protected by the passcode — treat backup files as sensitive. Local browser storage is encrypted when the Nexus lock is enabled.
                              Request passcode on launch
                              On — a fresh Nexus launch asks for your passcode. Off — Nexus can auto-unlock this browser profile until the selected re-entry interval expires. Turning this off intentionally reduces passcode protection on this browser/device because a protected device-local key is kept for auto-unlock.
                              Re-enter passcode every
                              After you unlock Nexus, it will automatically require the passcode again when this interval expires. The timer uses elapsed time, does not reset just because you are active, and is checked again when the app returns from the background. Launch prompting is controlled separately above.

                              Sync devices
                              This device's name (shown to peers you pair with)
                              Connects two devices directly over the local network — no relay server, no STUN/TURN server, nothing external is ever contacted, not even to set up the connection. The trade-off: there's no server to hold a message for an offline device, so both devices need this dialog open at the same time to pair, and a pairing doesn't survive a page reload, so you'll re-pair (copy/paste two short codes) each time you want to sync this way. Once connected it stays open and syncs live until either side closes the app.
